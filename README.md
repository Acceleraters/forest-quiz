# 森林刷题册

V15.1：面向毛概、习概的静态网页刷题工具。包含 23 个章节、577 道题，支持电脑与手机浏览器使用，无需构建或安装依赖。

## 主要功能

- 每章全部题目练习、多章合并全刷、随机章节自测与综合模拟。
- 单选、多选和简答题；进入多选区域时提示，简答题先查看参考答案再自评。
- 本次考试错题、历史未完成错题、章节错题排名和独立错题重刷。
- 自动保存、暂停续做、答题卡、简答草稿、收藏与记忆练习。
- 手机底部答题按钮、横屏布局、安全区域适配和收起键盘入口。
- 学习记录导出和导入；保存失败时提示重试或导出。

章节全刷与错题重刷不会增加正式考试次数，也不会覆盖最近一次正式考试的答案快照。

## 使用

电脑下载并解压全部文件后，打开根目录的 `index.html`。也可通过静态网站托管服务提供网页地址，让手机浏览器访问。

入口、脚本、样式和 `data` 文件夹必须保持现有相对位置；只下载 `index.html` 不足以运行完整应用。

## 数据与隐私

学习记录保存在当前浏览器的本地存储中，没有服务器端账号或云同步。此仓库只包含程序和题库，不包含个人答题记录。

升级、换网址、换设备、清理浏览器数据前，请先在“设置”中导出备份。新环境可通过“导入学习数据”恢复；导入会替换当前浏览器中的记录，请先备份。

请勿将导出的个人学习备份上传到公共仓库。

## 文件

- `index.html`：网页入口。
- `app.js`：刷题和学习记录逻辑。
- `style.css`、`mobile-v15.css`：页面样式与手机适配。
- `data/question-banks.js`：网页直接读取的题库。
- `data/question-banks.json`：结构化题库源数据。

V15.1 已通过 Edge、WebKit 共 38 组回归检查，包括全部章节覆盖、暂停续做、错题统计、导入导出和移动布局。键盘、缩放、安全区域与后台时间使用受控模拟；尚未完成 iPhone 真机验收。
